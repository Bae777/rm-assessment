# RM 电控考核 · 正弦波跟踪 + 看门狗保护

用 GM6020 直流无刷电机跟随自定义正弦波的速度与位置曲线，并使用看门狗（IWDG）做保护。

## 三、控制流程

```
            1kHz 定时器中断（TIM6）
                    ↓
        ┌───────────────────────┐
        │ 生成正弦目标值         │   ref = A·sin(2πf·t)
        └───────────┬───────────┘
                    ↓
        ┌───────────────────────┐
        │ PID 计算              │   out = Pid.calc(ref, fdb)
        └───────────┬───────────┘
                    ↓
        ┌───────────────────────┐
        │ 组装 CAN 控制帧并发送  │   标识符 0x1FF / 0x2FF
        └───────────┬───────────┘
                    ↓
                GM6020 电机
                    ↓
        ┌───────────────────────┐
        │ CAN 中断接收反馈帧     │   标识符 0x204 + 电机ID
        └───────────┬───────────┘
                    ↓
        解码 → 角度 / 转速 / 电流 / 温度
```

## 四、GM6020 CAN 协议

### 反馈帧（电机 → 主控，1 kHz 自动发送）

标识符：`0x204 + 电机ID`（ID=1 → 0x205）

| 字节 | 内容 | 说明 |
|---|---|---|
| DATA[0..1] | 机械角度 | 0 ~ 8191，8192 = 一圈 |
| DATA[2..3] | 转速 | 单位 rpm（int16） |
| DATA[4..5] | 实际转矩电流 | int16 |
| DATA[6] | 电机温度 | ℃ |
| DATA[7] | 保留 | — |

### 控制帧（主控 → 电机）

| 标识符 | 覆盖电机 | 数据布局 |
|---|---|---|
| `0x1FF` | ID 1 ~ 4 | ID1→[0,1]，ID2→[2,3]，ID3→[4,5]，ID4→[6,7] |
| `0x2FF` | ID 5 ~ 7 | ID5→[0,1]，ID6→[2,3]，ID7→[4,5] |

电压给定范围：**-25000 ~ +25000**

## 五、关键实现要点

### 1. 正弦波生成 —— 相位累加器

不在中断里直接调用 `sin(2πft)`（需要维护时间变量且精度会漂移），而是用相位累加：

```c
phase += 2π · f · T;        // T = 0.001s，每拍相位前进
if (phase > 2π) phase -= 2π;
ref = A * sinf(phase);
```

**优点**：周期精确、无时间漂移、计算量小。

### 2. 角度累计 —— 跨零检测

电机反馈的机械角度是 0~8191，转一圈归零。若直接使用，跨零瞬间误差会突变一整圈，导致电机剧烈抖动。

处理方法（见 `src/Gm6020.cpp`）：

```c
int16_t diff = raw - last_raw_angle_;
if (diff > 4096)        full_turns_--;   // 8191 -> 0，正向转过一圈
else if (diff < -4096)  full_turns_++;   // 0 -> 8191，反向转过一圈
```

判断阈值取 4096（半圈）：因为 1 ms 内电机不可能转过半圈，所以变化超过半圈只能是跨零。

### 3. PID —— 位置式 + 抗积分饱和

离散公式：

```
u(k) = Kp·e(k) + Ki·Σe(j)·T + Kd·(e(k)-e(k-1))/T
```

其中 T = 0.001 s。

加入输出限幅与积分回退：输出饱和时撤销本拍积分累加，避免积分持续累积导致退出饱和过慢（见 `src/Pid.cpp`）。

### 4. 看门狗保护

- 使用独立看门狗 IWDG，CubeMX 中已开启；
- 预分频 `IWDG_PRESCALER_64`，重装载值 `400`；
- 超时时间 = 64 × 400 / 32000 Hz ≈ **800 ms**；
- **在 1 kHz 控制中断中喂狗**：只要控制回路停止运行，800 ms 内系统自动复位，避免电机保持最后一个电压值失控。

## 八、如何运行

1. 用 **STM32CubeMX** 打开 `C_project.ioc`
2. 生成 MDK-ARM 或 STM32CubeIDE 工程
3. 将 `src/` 下的文件加入工程
4. 在 `main.c` 中，`MX_XXX_Init()` 全部执行完毕后调用 `ControlTaskInit()`
5. 编译、下载

**接线**：GM6020 的 CAN_H / CAN_L 接到开发板 CAN1 接口，注意总线两端需接 120 Ω 终端电阻。
